# Exact counts and sharp growth for OEIS A222759, first comment (12 March 2013): extending Glaisher (1900)

*原论文：Haobo Ma、Wenlin Zhang，[第 2 版](https://doi.org/10.5281/zenodo.24405795)，CC BY 4.0。问题来自 T. D. Noe 于 2013 年 3 月 12 日在 [OEIS A222759](https://oeis.org/A222759) 留下的第一条评论。*

## 先看余数能有多大

固定一个正整数 $n$。对每个素数 $p$，从 $np$ 个物体中选出 $p$ 个，共有 $\binom{np}{p}$ 种选法。把这个数除以 $p^3$，取最小非负余数 $R_3(n,p)$。如果余数**不等于整数 $n$ 本身**，就把 $p$ 记为一个例外。设 $W(n)$ 是所有例外素数的集合，$a(n)$ 是其大小。

例如，$n=8$、$p=2$ 时，$\binom{16}{2}=120$，除以 $8$ 的余数是 $0$。虽然 $0$ 和 $8$ 模 $8$ 同余，余数仍然不等于 $8$。不必算出二项式系数也能判断：余数总在 $0$ 到 $p^3-1$ 之间。因此只要 $p^3\le n$，这个素数一定被计入，等号也算。

反过来，若 $p^3>n$，$n$ 就有资格成为余数，但还需要一条整除性质。对 $p\ge5$，[Glaisher 的同余式](results.md#lem-glaisher)恰好保证 $\binom{np}{p}-n$ 是 $p^3$ 的倍数。此时余数只能是 $n$。素数 $2$、$3$ 必须单独算：在 $n<8$ 时，$2$ 仅在 $n$ 除以 $4$ 余 $2$ 或 $3$ 时额外计入；在 $n<27$ 时，$3$ 仅在 $n$ 除以 $3$ 余 $2$ 时额外计入。

## 数台阶，而不是算大系数

从 $27$ 开始，两个额外条件都消失。数例外素数，就等于数不超过 $n$ 的素数立方。

| $n$ | $W(n)$ | $a(n)$ |
|---:|:---|---:|
| $5$ | $\{3\}$ | $1$ |
| $8$ | $\{2,3\}$ | $2$ |
| $9$ | $\{2\}$ | $1$ |
| $124$ | $\{2,3\}$ | $2$ |
| $125$ | $\{2,3,5\}$ | $3$ |
| $343$ | $\{2,3,5,7\}$ | $4$ |

早期的 $8,9$ 说明计数并非始终递增。但在第三个素数 $5$ 的立方处，第三个例外第一次出现；之后每遇到下一个素数的立方，计数就多一个。若 $p_k$ 表示第 $k$ 个素数（$p_1=2$），则对 $k\ge3$，至少有 $k$ 个例外的**充要条件**是 $n\ge p_k^3$。Noe 提出的条件是 $n\ge p_{p_k^3}$：先取立方，再把它当作素数序号。取 $k=3$ 时，原条件是 $n\ge691$，而准确门槛是 $125$。

## 数量和位置是两回事

[OEIS A222760](https://oeis.org/A222760) 问：从哪个最小的素数开始，那个素数以及之后的每个素数都不再是例外？这要找**最后一个**例外，而不是只数例外。$n=5$ 时只有 $3$ 是例外；虽然 $2$ 本身不是例外，从 $2$ 开始仍会遇到 $3$，因此答案是 $5$。其他输入的例外集合都是从最小素数起的一段（也可能为空）；此时答案是第 $a(n)+1$ 个素数。

从余数的取值范围出发，找出第三个例外第一次出现的地方。

余数范围的论证也适用于模 $p$ 和 $p^2$；不同的是，这两种模数下连 $2$ 和 $3$ 都无需额外计入。不能照搬到更高次幂：$\binom{10}{5}=252$，对每个 $e\ge4$，它除以 $5^e$ 的余数仍是 $252$，不是 $2$。这个反例否定了一致的同余式，并没有给出高次幂下的例外总数。
